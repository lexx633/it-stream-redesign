Правит тексты и кнопки лендинга. Сохранение коммитит content.json в GitHub — сайт обновится через 1–2 минуты.

Доступ к GitHub

Токен сохраняется в localStorage этого браузера и никуда, кроме api.github.com, не отправляется. Создать: GitHub → Settings → Developer settings → Personal access tokens.

Как добавить новое поле
1. В index.html добавь элементу атрибут data-cms="раздел.ключ" (для текста с разметкой — ещё data-cms-html, для ссылки — data-cms-href="ключ").
2. В content.json добавь этот ключ со значением. Поле само появится здесь.

Что пока не редактируется здесь

Карточки услуг, кейсы, отзывы, вопросы FAQ и цены калькулятора правятся прямо в index.html. Их можно вынести в этот редактор тем же приёмом data-cms — это следующий шаг основы.
